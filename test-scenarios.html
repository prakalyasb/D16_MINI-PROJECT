Automated Java Test Scenarios

Execute automated operational scenarios matching the test suite of the Java backend. Observe how bookings fill to capacity, waiting queues enforce strict FIFO fairness, and cancellations trigger automatic promotions into freed seats.

TEST 1

Cancelled Seat & Promotion

Books 10 passengers onto Train T001 to reach full capacity, adds waiting passengers, and then cancels a confirmed reservation (Seat #4). Verifies that the front waiting passenger is automatically promoted into Seat #4 in strict FIFO order.

TEST 2

Overlong Train

Tests track routing constraints when a train length (e.g. 480m) exceeds a platform's physical length limit (e.g. 300m or 400m).

TEST 3

Overlapping Arrival

Tests conflict resolution and track assignment when two scheduled trains request the same platform during overlapping time intervals.

TEST 4

Schedule Delay Cascade

Tests priority preemption and downstream delay propagation when an inbound service encounters a transit delay.
